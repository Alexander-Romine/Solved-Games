# Solved Games

A website that showcases solved games.

**Live site:** https://solved-games.vercel.app

![Solved Games screenshot](screenshot.png)

## Games

- Connect 4
- Tic-Tac-Toe
- Nim
- Mancala
- Reversi
- Checkers

## Tech Stack

- [Vite](https://vite.dev/)
- TypeScript
- Hosted on [Vercel](https://vercel.com)
